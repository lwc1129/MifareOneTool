Windows NFC Tools (nfc-bin)
==========================

Place the following Windows executables in this folder:

  nfc-scan-device.exe   — list connected NFC devices
  nfc-mfclassic.exe     — read / write Mifare Classic cards
  nfc-list.exe          — detect card UID
  mfoc.exe              — offline nested attack (crack unknown keys)
  mfcuk.exe             — dark-side attack (very slow brute force)
  nfc-mfsetuid.exe      — write UID to magic / UID-changeable cards

Download pre-built Windows binaries from:
  https://github.com/nfc-tools/libnfc/releases
  https://github.com/nfc-tools/mfoc/releases

After placing the files, the application will detect them automatically.
